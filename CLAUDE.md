# fixbox-web — контекст проекта

## Цель

Сайт для сервисов Fixbox. Главная задача — не сам сайт, а **повышение ранжирования
бизнеса в Google Maps** (локальное SEO): страница-визитка + страницы услуг с
корректной schema.org-разметкой `LocalBusiness`, на которую ссылается
Google Business Profile.

Старый сайт не оплачен, этот выносим на бесплатную площадку.

## Принятые решения

- Репозиторий: публичный `KefirNot/fixbox-web` на GitHub (публичный — ради
  бесплатного GitHub Pages).
- Хостинг: GitHub Pages (деплой через GitHub Actions) — предварительно, ещё не настроен.

## Открытые вопросы (решить до контента)

1. **Стек**: Astro (если страниц услуг будет 5+) или голый HTML (если 1–2 страницы).
   Пока не решено, обсуждалось 2026-07-31.
2. **Список услуг** — что именно ремонтирует/делает Fixbox, какие страницы нужны.
3. **NAP-данные**: название, адрес, телефон — строго как в Google Business Profile,
   совпадение критично для ранжирования.
4. **Язык контента** сайта.
5. **Домен**: старый домен продлеваемый или потерян? Если сайт будет на
   `*.github.io`, надо сменить ссылку в Google Business Profile. Свой домен
   (~$10/год) для ранжирования заметно лучше бесплатного поддомена — рекомендовано.
6. **Контент старого сайта**: есть ли бэкап или адрес (можно вытащить из веб-архива).
